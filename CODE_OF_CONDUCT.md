# Code de conduite

## Notre engagement

En tant que contributeurs et contributrices, nous nous engageons à faire de la participation à ce projet une expérience respectueuse et sans harcèlement pour tout le monde, quels que soient l'âge, l'apparence, le handicap, l'origine, l'identité ou l'expression de genre, l'orientation sexuelle, le niveau d'expérience, la religion ou la nationalité.

## Ce que nous attendons

- Être bienveillant et respectueux, y compris dans les relectures de code.
- Critiquer le code, jamais la personne.
- Accepter les remarques constructives et reconnaître ses erreurs.
- Privilégier ce qui est le mieux pour le projet et l'équipe.

## Ce qui n'est pas acceptable

- Les propos ou images à caractère sexuel, les insultes, les moqueries et les attaques personnelles.
- Le harcèlement, public ou privé.
- La publication d'informations privées d'une autre personne sans son accord.

## Signalement

Tout comportement inacceptable peut être signalé à un membre de l'équipe ou à l'équipe pédagogique. Les signalements sont traités avec discrétion.

## Attribution

Ce code de conduite est adapté du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/), version 2.1.
